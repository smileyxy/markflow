3 步快速上手指南

步骤 1

配置 AI 模型（可选，30 秒完成）

前往「AI 语义模型」选择服务商并填入 API Key，点击测试连接通过后保存即可启用自动命名与归类。

步骤 2

随时按 Alt + B 收藏，按 Tab 极速找书签

浏览任意网页时按下快捷键呼出浮窗，确认标题与推荐目录后按 Enter 保存；新标签页按快捷键直达检索模式。

快捷键：Alt + B 呼出 · Tab 切换检索 · Enter 确认
步骤 3

一键整理存量书签或定制高频规则

在「智能整理」体验 0 Token 目录内排序或全盘目录重构（变更前自动备份）；高频域名可在「规则引擎」设为 0ms 直达。

隐私与安全合规承诺 (Privacy Guarantee)

  • 零服务器运营架构：插件全部逻辑运行在本地浏览器内，无中央后端服务器，不托管任何用户数据。
  • 零遥测与追踪：绝不收集、统计或上传您的浏览历史、访问记录与书签库内容。
  • 最小化按需授权：仅在您主动按下快捷键唤醒插件时读取当前标签页信息，并可随时一键关闭正文摘要提取。
  • 原生兼容多端同步：所有书签直接写入浏览器原生书签树，无缝触发浏览器云端同步。
